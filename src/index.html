Sources and scope

This independent reconstruction preserves the LOTS domain index in a simple, searchable format inspired by LOLBAS. Credit for the original Living Off Trusted Sites project belongs to mrd0x and its contributors.

All 175 domains, original abuse tags, and 123 service providers were recovered directly from the saved October 6, 2026 Wayback snapshot. Provider names and tags are preserved as published. Each record links to the original LOTS detail page on Wayback; those detail pages were not included in the saved archive and may not be available.

Entries marked “new” were added to this reference and are supported by linked primary reports. “New” refers to inclusion here, not when the abuse began. Each includes publication dates, the reported activity window, review date, and hunting ideas. A review date is not a last-seen timestamp. These entries do not claim ongoing malicious use today.

Use the index for investigation, not as a blanket blocklist. Original archive JSON · Research JSON · Data provenance and licensing. Original code and independently written notes use the MIT license; the inherited LOTS dataset has no identified license.
